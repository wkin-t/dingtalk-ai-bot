# Gemini 主路径失败时使用 Vertex 保底

**Status: accepted**

Gemini 文本请求采用“主路径建流失败即切换 Vertex 保底”的容错边界：provider 建流阶段的任意异常都打开短期熔断并重试一次，已产生用户可见输出后的流中异常不重放，任务取消和本地转换错误也不触发熔断。这样可以在不重复输出的前提下利用 Vertex pay-as-you-go 保证可用性；代价是主路径的配置或上游问题会在冷却窗口内被整体旁路，且保底模型的兼容性依赖服务端 alias。生图/改图保持独立直连路径，原生 SDK 搜索与旧搜索摘要 fallback 分别拥有独立开关。
